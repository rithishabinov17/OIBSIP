# 🌤️ Basic Weather App

A simple Python-based Weather Application that fetches real-time weather information using the **OpenWeatherMap API**.

## 📌 Project Overview

The Basic Weather App allows users to enter a city name and retrieve current weather information.

The application displays:

* 🌡️ Temperature in Celsius
* 🌡️ Temperature in Fahrenheit
* 💧 Humidity
* ☁️ Weather condition
* 💨 Wind speed
* 🌍 Country information

## 🛠️ Technologies Used

* Python
* Requests Library
* OpenWeatherMap API

## ✨ Features

* Search weather by city name
* Real-time weather information
* Celsius and Fahrenheit temperature
* Humidity information
* Weather condition
* Wind speed
* Error handling for invalid cities
* API error handling
* Network timeout handling

## ⚙️ Installation

### 1. Install Python

Download and install Python from the official Python website.

### 2. Install Requests

Open Command Prompt or terminal and run:

```bash
pip install requests
```

### 3. Get an OpenWeatherMap API Key

Create an account on OpenWeatherMap and generate an API key.

Add your API key inside `weather_app.py`.

**Important:** Do not upload your real API key to GitHub. Use an environment variable or replace it with a placeholder before publishing.

## ▶️ How to Run

Open the project in Python IDLE or VS Code.

Run:

```bash
python weather_app.py
```

Enter a city name when prompted:

```text
Enter city name or ZIP code: Chennai
```
