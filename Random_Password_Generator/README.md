# Random Password Generator

A secure and user-friendly desktop application developed using Python and Tkinter to generate strong random passwords.

## Project Overview

Random Password Generator is a Python-based desktop application that allows users to generate secure passwords by selecting the required password length and character types.

The application uses Python's `secrets` module for secure random password generation and Pyperclip for copying passwords to the clipboard.

## Features

- Generate secure random passwords
- Select password length from 8 to 50 characters
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Password strength indicator
- Copy password to clipboard
- Last 5 generated passwords
- Clear password history
- Input validation
- Error handling
- Professional Tkinter user interface

## Technologies Used

- Python
- Tkinter
- Secrets
- String
- Pyperclip

## Python Modules

### Tkinter

Used to create the graphical user interface.

### Secrets

Used to generate secure random passwords.

### String

Used to provide uppercase letters, lowercase letters, numbers, and symbols.

### Pyperclip

Used to copy the generated password to the system clipboard.
