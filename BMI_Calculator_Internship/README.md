# BMI Calculator

A professional BMI Calculator desktop application developed using Python, Tkinter, and SQLite.

## Technologies Used

- Python
- Tkinter
- SQLite

## Features

- BMI Calculation
- BMI Category
- Save BMI History
- View History
- Search History
- Delete History
- Clear All History
- Professional User Interface

## BMI Categories

- Underweight
- Normal
- Overweight
- Obese

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the Python file.

```bash
python bmi_calculator.py
