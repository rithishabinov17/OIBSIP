# Voice Assistant Using Python

## Project Overview

This project is a Python-based Voice Assistant developed using Python. It can recognize voice commands through a microphone and respond using voice output.

## Features

- Voice input
- Speech recognition
- Voice response
- Google search
- YouTube search
- Open Google
- Open YouTube
- Open Notepad
- Open Calculator
- Open File Explorer
- Open VS Code
- Current time
- Current date
- Basic calculator
- Continuous voice commands

## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- Webbrowser
- Datetime
- Windows PowerShell Speech

## Project Structure

Voice_Assistant_Internship/

├── voice_assistant.py

└── requirements.txt

## Installation

Install the required packages using:

pip install -r requirements.txt

## How to Run

Run the following command:

python voice_assistant.py

Then speak a command through the microphone.

## Sample Commands

- Hello
- How are you
- What is your name
- Open Google
- Open YouTube
- Search Google Python
- Search YouTube Python tutorial
- What time is it
- What is the date
- Calculate 25 plus 10
- Open Notepad
- Open Calculator
- Exit
